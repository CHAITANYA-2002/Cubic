# Display and currency subsets

Official Google Fonts text subsets of Cormorant Garamond (600 normal/italic) and Inter (rupee glyph), under the SIL Open Font License files in this directory.

Sources: https://fonts.google.com/specimen/Cormorant+Garamond and https://fonts.google.com/specimen/Inter.

Downloaded from the Google Fonts CSS API and self-hosted. Browsers make no Google Fonts requests. Original full faces remain for glyph fallback.
